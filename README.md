# EcoShot

Foto-App im Browser mit Sprachsteuerung. Sag „Mache ein Foto in 5 Sekunden“, dann zählt ein Countdown herunter und die Kamera löst aus.

Läuft in Safari (iPhone) und Chrome. Kamera und Mikrofon brauchen HTTPS, deshalb wird die Seite über GitHub Pages veröffentlicht.

Fotos speicherst du nach der Aufnahme mit „In Fotos sichern“.
